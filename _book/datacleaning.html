library(tidyverse)
Code
set.seed(20261019)
n <- 60
dat <- tibble(study_id = 1:(2 * n),
              first = sample(LETTERS, 2 * n, replace = TRUE),
              last = sample(LETTERS, 2 * n, replace = TRUE),
              inclusion_over17 = 1,
              inclusion2 = 1, inclusion3 = 1, inclusion4 = 1,
              exclusion1 = 0, exclusion2 = 0,
              screened = 1,
              informed_consent = rbinom(2 * n, 1, 0.9),
              endpoints =  rbinom(2 * n, 1, 0.9),
              age_today = floor(runif(2 * n, 25, 45)),
              gender = rbinom(2 * n, 2, 0.250),
              video_games = rbinom(2 * n, 4, 0.2),
              randomization_group = rep(0:1, n)) |> 
  mutate(reverse_digit = rnorm(2 * n, 3 + 2 * randomization_group, 1.5),
         reverse_digit = round(reverse_digit),
         cold_pressor = rnorm(2 * n, 60 - 10 * randomization_group, 20),
         cold_pressor = round(cold_pressor),
         video_challenge = rbinom(2 * n, 1, 0.2 + 0.3 * randomization_group)) |> 
  mutate(across(age_today:video_challenge, ~ ifelse(informed_consent == 1, .x, NA))) |> 
  mutate(across(reverse_digit:video_challenge, ~ ifelse(endpoints == 1, .x, NA))) |> 
  select(-endpoints) 

sm <- dat |> 
  select(-(inclusion_over17:screened)) |> 
  rename(id = study_id,
         trt = randomization_group,
         age = age_today) |> 
  mutate(gender = factor(gender, 0:2, c("F", "M", "O")),
         trt = factor(trt, 0:1, c("control", "intervention")),
         video_games = factor(video_games, 0:3, 
                              c("<30 minutes per day", "30-60", "60-120", "120+"))) |> 
  filter(!is.na(trt), !is.na(reverse_digit))

To make a smaller cleaned version of the data for analysis, we might consider doing the following:

  1. Remove screening variables. Choosing variables to keep is done with select(), e.g. select(var1, var2). If you just want to drop a few variables, try select(-var1, -var2).
  2. Rename study_id to id, randomization_group to trt, age_today to age. Renaming variables can be performed by typing using rename() , like rename(newname = oldname).
  3. Give labels to gender, trt and video_games. The command mutate() can be used to make various changes to variables. Specifically, in these cases, we need to also use factor(). If, for example, we have a 0/1 variable called var where 0 means “no” and 1 means “yes”, we could write mutate(var = factor(var, c(0, 1), c("no", "yes")). We can also put multiple changes to multiple variables inside mutate().
  4. Filter out participants that are not randomized and do not have the primary endpoint. For this, there are two options filter() or filter_out(). If you use filter(), write out conditions which should be met (“inclusion criteria”). Alternately, if you use filter_out(), write out conditions which should not be met (“exclusion criteria”). Multiple conditions can be separated by a comma, and will be combined with AND (&). If you want OR, you could write | instead of a comma. For example, to keep female participants aged 45 or older, we could write filter(gender == 0, age_today >= 45).

All of these functions are in the dplyr package.

8.1 Make a demographics table

From the dataset we made in the last step, we probably want to include age, gender, video_games and report summary statistics by trt. Using the R package gtsummary, we can do this with the function tbl_summary() (see also the introduction on the gtsummary website).

Important

According to both the CONSORT and STROBE guidelines, “significance testing of baseline differences is not recommended and should not be reported” and “p-values are not an appropriate criterion for selecting which confounders to adjust for in analysis”. Do not be tempted to add p-values, using add_p(), to these kinds of tables if they are used to compare baseline characteristics!

To clean up or improve the table, try customizing it with options like label, value, digit or statistic. Use the forcats package gives us more ways to deal with factor variables, in this case, the fct_recode() function for change labels on the levels of the factor.

library(forcats)
sm |>

## Make a demographics table

Now that we've cleaned the dataset, let's make a table of baseline characteristics. From the dataset we made in the last step, we probably want to include `age, gender, video_games` and report summary statistics by `trt`. Using the R package [`gtsummary`](https://www.danieldsjoberg.com/gtsummary/), we can do this with the function `tbl_summary()` (see also the [introduction](https://www.danieldsjoberg.com/gtsummary/articles/tbl_summary.html) on the `gtsummary` website).

```{r table1}
library(gtsummary)
sm |> 
  select(trt, age, gender, video_games) |> 
  tbl_summary(by = trt)
```

:::
