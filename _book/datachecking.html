library(tidyverse)

Now, imagine we have just completed a randomized clinical trial.

  • Population: students in this course
  • Intervention: watching a concentration video for 5 minutes
  • Control: watching a screensaver-type video for 5 minutes
  • Outcome: reverse digit span test

The primary outcome is the reverse digit span test, a computer-based test of memory (high number of digits is better). Secondary outcomes are the cold pressor test (number of seconds you can keep your hand in ice cold water), and a video challenge, that participants either complete or do not.

Note

This dataset is not real, just simulated. If you want to use it, unfold the code here.

Code
set.seed(20261019)
n <- 60
dat <- tibble(study_id = 1:(2 * n),
              first = sample(LETTERS, 2 * n, replace = TRUE),
              last = sample(LETTERS, 2 * n, replace = TRUE),
              inclusion_over17 = 1,
              inclusion2 = 1, inclusion3 = 1, inclusion4 = 1,
              exclusion1 = 0, exclusion2 = 0,
              screened = 1,
              informed_consent = rbinom(2 * n, 1, 0.9),
              endpoints =  rbinom(2 * n, 1, 0.9),
              age_today = floor(runif(2 * n, 25, 45)),
              gender = rbinom(2 * n, 2, 0.250),
              video_games = rbinom(2 * n, 4, 0.2),
              randomization_group = rep(0:1, n)) |> 
  mutate(reverse_digit = rnorm(2 * n, 3 + 2 * randomization_group, 1.5),
         reverse_digit = round(reverse_digit),
         cold_pressor = rnorm(2 * n, 60 - 10 * randomization_group, 20),
         cold_pressor = round(cold_pressor),
         video_challenge = rbinom(2 * n, 1, 0.2 + 0.3 * randomization_group)) |> 
  mutate(across(age_today:video_challenge, ~ ifelse(informed_consent == 1, .x, NA))) |> 
  mutate(across(reverse_digit:video_challenge, ~ ifelse(endpoints == 1, .x, NA))) |> 
  select(-endpoints) 

sm <- dat |> 
  select(-(inclusion_over17:screened)) |> 
  rename(id = study_id,
         trt = randomization_group,
         age = age_today) |> 
  mutate(gender = factor(gender, 0:2, c("F", "M", "O")),
         trt = factor(trt, 0:1, c("control", "intervention")),
         video_games = factor(video_games, 0:3, 
                              c("<30 minutes per day", "30-60", "60-120", "120+"))) |> 
  filter(!is.na(trt), !is.na(reverse_digit))

Use nrow() to find out how many participants have been screened.

Code
nrow(dat)

7.3 Q: How many of them have been randomized?

A common thing to check when you’re first looking at a dataset is how many of something there are. How many participants? How many participanted have been randomized? How many are at least 18 years old? For these tasks, we need count(). Using dplyr coding style, we write the name of the dataset, dat, write “then” using the so-called “pipe” |> (or %>%, either way it’s ctrl / cmd + M), and finally count().

Code
dat |> 
  count()
# A tibble: 1 × 1
      n
  <int>
1   120

This count should be the same as we got above with nrow().

We want to see how many participants are in each category of randomization_group, or where it is missing. So let’s count() randomization_group.

Code
dat |> 
  count(randomization_group)
# A tibble: 3 × 2
  randomization_group     n
                <int> <int>
1                   0    54
2                   1    58
3                  NA     8

7.4 Q: How many have the primary endpoint, the reverse digit span test?

The is.na() function checks if a value is missing (NA). To check if it’s not missing, use !is.na() (! means “not”).

Code
dat |> 
  count(!is.na(reverse_digit))
# A tibble: 2 × 2
  `!is.na(reverse_digit)`     n
  <lgl>                   <int>
1 FALSE                      18
2 TRUE                      102

  1. Talk to the study coordinator;
